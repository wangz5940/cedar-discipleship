# OVCM 播放器静态依赖

本目录作为共享项目资源保存 OVCM 课程播放器的固定版本，用于保留已确认的原版界面、颜色标识和播放交互。页面来源为 https://ovcm.net/tx2026/ 。文件名中的内容标识及 `assets.sha256.json` 固定当前分发版本，不在启动时自动跟随第三方更新。

- `assets/` 是第三方发布文件，不是 Cedar 的构建输出；保留文件内已有的作者与许可说明。不要在其中做常规格式化。
- `index.html` 是 Cedar 的嵌入入口：调整静态路径、隐藏重复导航，并发送课程路由事件。
- `cedar-theme.css` 将原版播放器的品牌色映射到网站现有配色，保留课时与分段的颜色标识。
- `memory-bridge.js` 是 Cedar 的账号进度和系统媒体控制桥接代码。
- `assets/services-analytics-ByXyS-c7.js` 已替换为空实现，嵌入播放器不启用原站分析上报。
- 音视频、封面与讲义仍使用课程目录中的外部地址，不包含用户账号、上传文件或数据库数据。

更新时保持依赖文件及入口一致，重新记录 SHA-256，验证播放、进度恢复、路由、讲义和账号切换。发布方应确认所用第三方内容的使用与分发条件；本项目不改变第三方内容的权利归属。

课程目录通过 `/api/ovcm/catalogue` 每分钟检查源站更新，在共享资源的 OVCM 共用根资源库中展示同一份课程和资料链接。服务端将最近成功快照保存在资源目录的 `.ovcm/catalogue.json`，失败及重启期间继续使用该快照，首次同步前回退至随发布保存的目录。只更新课程数据，播放器分发版本仍保持固定；`catalogue=1` 入口将选中课程的已解析数据注入固定播放器，保留课时 ID、分段、字幕、英文音轨及资料地址。目录同步无需下载媒体文件或配置 OVCM 账号，课程与收藏仍使用网站原有密钥访问规则。
